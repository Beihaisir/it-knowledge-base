## 现象

用户反馈"SS系统进不去"、"登录不了"、"点什么也不好使"。此问题常为**集中性故障**（多公司同时报）或**单点问题**（个别电脑/地磅）。

## 排查步骤

### 1. 先判断是否集中性故障

多公司同时报 → 大概率**机房/服务器**问题，立即上报北京 IT，通知群里"机房正处理，5-10 分钟，先不要操作"。

![[assets/ss-login-flow.svg|集中故障 → 机房处理；单点故障 → 本地排查]]

### 2. 单点故障排查顺序

1. **改用域名登录**（不用 IP）：

```
smartsoftn.cpchina.cn
```

2. **检查远程桌面连接**：VPN 是否正常，`ping` 服务器是否通
3. **重建远程桌面快捷方式**：地磅电脑常见问题——`ping` 通但连不上，新建快捷方式即可
4. **换电脑验证**：同一账号在其它电脑能打开 → 本机/本服务器问题
5. **本地打印机/服务器打印机**：进不去时顺带看服务器打印机界面是否正常加载

### 3. 关键经验

- 登录前确认**所有勾选项都打勾**（部分用户漏勾导致进不去）
- 服务器问题要等北京 IT 处理，**不要反复操作**避免二次故障
- 处理完要在群里通知"好了"，让所有公司重试
