## 收货流程要点

### 1. 排号与先进先出

- 同供应商同原料同包装形式 → 按**先进先出**收货
- 排号顺序 = 合同先后，不能跳单
- 如需非先进先出，要**申请**，不能自己跳

### 2. 标包/散料收货

- 排号类型：1 = 散料，2 = 标包
- 二磅前发现标包/非标包有问题 → 按 GBM29000 修改设定
- 散料非标包收货：FMM35000 打勾 → 排号类别=1

### 3. 无法挂装卸费（合同首日到货）

- 用 `PUM01902` 查询该合同
- 看合同是否做了**采购费用**（SCIS 端查）
- 没有价格/费用 → 先补采购费用

## 入库异常处理

### 原料代码转换

本月做过 FMM55 原料代码转换，没有被 ML 移库和耗用：
- 可用恢复操作菜单 **FMU04000** 做逆向
- 已做后续处理或跨月 → 联系财务做**非生产出入库**

### 非生产出入库（NS 库位）

NS 库存处理流程：
1. STI12000 看这条明细有没有 **pending** 状态
2. 没有 → 财务做非生产出库 NS 仓位
3. 非生产入库到 XA01
4. FMM36000 正负核销

### 库位设定问题

NS 库位是外地的（如桂林 0102），本地无法操作时：
- 请 IT/财务在 **STM19000** 设定里把 NS 仓位改成当地仓库分库代码

## 关键菜单

| 菜单 | 用途 |
|------|------|
| FMM06000 | 入库 |
| FMM05000 | 过磅 |

| FMM36000 | 正负核销 |
| FMM55 | 原料代码转换 |
| FMU04000 | 转换恢复逆向 |
| PUM01902 | 合同查询 |
| STM19000 | 库位设定 |
