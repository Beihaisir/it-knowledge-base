## 现象

- 单据显示"无法重新发送 SAP"
- 因折扣冻结无法过磅，解锁后单据"消失"
- 调整单据没发送 SAP 成功
- 属地 BP 只有 43 单据权限，没有 42 单据权限

## 排查步骤

### 1. 信审状态是核心

**出库看不到单号 → 先看信审通没通过**：

```
RCI019S0 查看信审状态
```

> 信审没通过当然不能出库。单据没消失，是状态不对。

### 2. 折扣冻结 → 解锁流程

1. 折扣冻结导致无法过磅
2. 解锁后单据在 RCI019S0 菜单**发送**
3. 发送后出不了库 → 检查是否**重新生成 53 单据**

> 解冻后要重新生成 53，不然信审不过。

### 3. 恢复 42 单据权限

调整单据未发送 SAP 成功，属地 BP 没有 42 权限时：

```
PUU01200 是恢复 42 的
```

### 4. 退货单逻辑（43）

- 43 = **采购退货**
- 61 = 生产入库，不能直接做 43 退货
- 全部退货只能退对应 **41 仓位**的
- 品管部二次检测没过也会导致不能操作——先确认流程节点

## 关键菜单

| 菜单 | 用途 |
|------|------|
| RCI019S0 | 信审状态查询/发送 |
| PUU01200 | 恢复 42 单据权限 |
| FMM31000 | 开单 |

## 参考

- "单据消失" 90% 是信审未过 + 未重新生成 53
- 描述问题要带菜单名+单号，别说"SS没了"
