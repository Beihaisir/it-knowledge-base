## 现象

- 过磅界面一直不显示磅重
- 无法过二磅，点击票据搜索搜不出来
- 地磅电脑进不去系统

## 排查步骤

### 1. 硬件层：串口/端口

按顺序检查：
1. **换端口了？换电脑了？** 先确认环境变更
2. **检查端口是否正常**
3. **地磅串口工具能否收到数据**——串口工具没数据 = 硬件/线缆问题，不是系统问题
4. 重启端口试试

### 2. 软件层：手工模式

**关闭手工模式**！多个案例是手工模式没关导致不过磅/不显示。

- 确认"没有开手工模式"
- 卡 FMM5000 窗口 → **主端口重启**

### 3. 过二磅搜不出票据（散装车）

> 散料的在线支付订单**超发**了 → 需要客户去**猪博士**上点"待补款"或"拒绝补款"。
> 必须让客户操作，不是本地能解的。

### 4. 排号类别

收货时 `FMM06000` 入库和 `FMM05000` 过磅会显示排号类型：
- 1 = 散料
- 2 = 标包

## 关键菜单

| 菜单 | 用途 |
|------|------|
| FMM05000 | 过磅 |
| FMM06000 | 入库 |
| FMM5000 | 过磅主窗口（卡住则重启） |
| FMM31000 | 开单（饲料厂销管） |

## 参考

- 散料按 FMM35000 反向修改打勾 → 排号类别=1
- 硬件问题（串口）先于软件问题排查
