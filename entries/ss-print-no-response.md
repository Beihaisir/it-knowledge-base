## 现象

- 成品发货单打印没反应
- 显示"打印成功"但成品出库界面搜不到单号
- 原料超收单想重新打印

## 排查步骤

### 1. 打印无反应的常见原因

**发送 SAP 接口有问题卡住了**。开票菜单没反应 = 接口堵塞，重进系统或稍等再试。

### 2. 打印成功但搜不到单号

**先查信审状态**：菜单 `RCI019S0` 看信审是否通过。

> 信审没通过 → 不能出库。这是最常见的"单据消失"真相。

### 3. 单据"消失"的口径统一

排查时把话说清楚：
- **开单菜单** `SLM01940` 不会无缘无故消失
- 出库看不到 = 信审未过 或 SAP 未发送成功
- 截图要以**具体菜单 + 单号**为准，别说"SS里没了"

## 打印机专项

服务器上打印机界面 ≠ 本地电脑打印机：
- 先看**服务器**打印机界面（不是自己电脑的）
- 看本地电脑打印机加载是否正常
- 排查 IP 冲突：打印机 IP 被占会导致连不上

## 参考

- 信审查询：`RCI019S0`
- 开单菜单：`SLM01940`
