## 常见报错与处理

### STG05100 报错

- 现象：操作报错，无从下手
- 处理：按报错提示的**前置设定**排查（如 STG10000 第一次用，先看设定都配了没）

### 无法挂装卸费

- 首日到货无法挂装卸费
- 处理：PUM01902 查合同 → 确认采购费用是否已做（SCIS 端）

### 折扣冻结无法过磅

- 处理：折扣解锁 → RCI019S0 发送 → **重新生成 53** → 信审通过

### 无法过二磅/搜不出票据（散装车）

- 处理：在线支付订单**超发** → 客户去猪博士点"待补款/拒绝补款"

### 库存负数

- 处理：检查 PK01 仓位是否足够（编织袋），STI12000/STI11000 查位置

### 报错但重试就好

- 部分报错是**瞬时接口问题**（SAP 卡住），重试即可
- 连续报错才深挖

## 排查通用原则

1. **截图留证**：带菜单名 + 单号 + 时间
2. **说清菜单**：别说"SS出问题了"，说"FMM06000 打不开"
3. **先设定后单据**：GBM 系列设定错了，单据怎么做都错
4. **硬件优先**：地磅/打印机类问题先查硬件层
5. **别反复操作**：集中故障等机房通知，避免二次故障

## 参考

- 菜单号 = 定位问题的第一线索
- 记录每次处理过程，沉淀成自己的排障手册
