## 概述

SS 系统的 **GBM 系列**是基础资料/设定菜单，大多数"看起来是系统 bug"的问题，根源都在设定上。

## 高频设定问题

### 1. 标包 vs 散料（GBM29000）

- 标包非标包看 **GBM29000 是否打勾**
- 散料 = GBM29000 里"按公斤计算"打勾的
- 两个散料不能同时开采购单
- 修改过 GBM29000 标包/非标包设定会影响收货

> 案例：产品收货显示标包，但应按毛重-袋重收货 → GBM29000 录入时标包没打勾。

### 2. 客户属性（GBM15000）

搜索不到合同/代码时查：
- **GBM15000 状态是否有效**
- 是否是客户属性

### 3. 部门设定（GBM03100）

- 设定里选项是 `I` → 应在特殊生产阶段勾选
- 普通部门应为 `F` 属性
- 特殊阶段在 GBM56000 勾选该部门

### 4. 出入库单据拷贝（GBM44800/GBM68000）

- 先拷贝 GBM44800 出入库单据
- 打开 GBM68000
- 点确定后重新进 GBM44800 点搜寻

### 5. 发送菜单搜不到代码

发送菜单只能搜到**已审核**的代码：
- GBM29000 确认代码是否在 **MDM** 存在
- 存在但发送找不到 = 有人修改未审核 → **发邮件申请审核**

### 6. 生效日期更新

生效日期 1 号，但设定前已做了 50/51 单据 → 去 **OTG09000 更新**

## 常见菜单速查

| 菜单 | 用途 |
|------|------|
| GBM29000 | 原料/标包散料设定 |
| GBM15000 | 客户/代码状态 |
| GBM03100 | 部门设定 |
| GBM56000 | 特殊生产阶段 |
| GBM44800 | 出入库单据拷贝 |
| GBM68000 | 单据处理 |
| GBM05000 | 用户权限 |
