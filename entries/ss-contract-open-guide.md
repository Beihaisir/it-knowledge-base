## 现象

- SS 系统搜不到代码，无法开立合同
- 合同搜不到/查不到状态
- 开单菜单没反应

## 排查步骤

### 1. 搜不到代码/合同

1. **代码是否在 MDM 存在**（GBM29000 确认）
2. 存在但搜不到 = 修改未审核 → 发邮件申请审核
3. **大料不能直接在公司 SS 开合同** → 去**微信平台**开

### 2. 查合同状态

- `PUM01902` 查询合同，看**是否关闭**
- 看生效日期与设定时间：生效日期在设定前，已做 50/51 单据 → 去 `OTG09000` 更新

### 3. 合同首日无法挂装卸费

- PUM01902 点查询看合同
- 没有内容/价格 → SCIS 端查**采购费用**做了没

### 4. 属地财务已下载但 SS 搜不到

- 属地财务在财务系统下载了代码
- SS 搜不到 → 代码未同步/未审核，联系审核

## 关键菜单

| 菜单 | 用途 |
|------|------|
| PUM01902 | 合同查询 |
| OTG09000 | 生效日期更新 |
| GBM29000 | 代码/MDM 确认 |
| SLM01940 | 开单菜单 |

## 参考

- 合同问题 90% 是状态/审核/平台问题，先查状态再找系统
- 大料合同走微信平台，不进 SS
